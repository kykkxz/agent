# 📋 随堂综合实战任务：AI 智能名片生成器

## 一、任务背景

你是公司新入职的"AI 应用开发实习生"。今天产品经理给你提了一个需求：做一个"AI 智能名片生成器"——输入一个人的基本信息，AI 自动生成一张结构化的电子名片，包含：

* **一段简洁的自我介绍**（用于社交场合）
* **一句个人 slogan**（用于签名档）
* **结构化的名片数据**（JSON 格式，方便系统存储）

## 二、任务目标

综合运用今天学过的 LangChain 知识，完成一个完整的 AI 名片生成程序。

* * *

## 三、任务要求

### 第 1 步：环境配置

1. 创建 `.env` 文件，配置 `API_KEY`、`BASE_URL`、`MODEL_NAME`
2. 使用 `load_dotenv()` 读取环境变量

### 第 2 步：初始化模型

使用 `ChatOpenAI` 初始化一个大模型实例，要求：

* 从环境变量读取配置
* `temperature` 设为 `0.3`（让输出稍微有点创意，但又不太离谱）

### 第 3 步：生成自我介绍（使用 LCEL 链式调用）

使用 `ChatPromptTemplate` + LCEL（`|` 管道符）+ `StrOutputParser` 完成：

1. 创建一个 `ChatPromptTemplate`，包含：
   * `system` 角色：你是一个专业的人力资源顾问，擅长帮人写简洁有力的自我介绍
   * `human` 角色：请根据以下信息，帮我写一段 50 字以内的自我介绍。姓名：`{name}`，职位：`{job}`，技能：`{skills}`
2. 用 LCEL 语法组装：`chain = prompt | llm | StrOutputParser()`
3. 调用 `chain.invoke()` 生成自我介绍
4. 打印结果，并验证返回类型是 `str`

### 第 4 步：生成个人 slogan（使用 PromptTemplate）

使用 `PromptTemplate` 完成：

1. 创建一个纯文本模板，内容如："请根据以下信息，生成一句 15 字以内的个人 slogan，要求朗朗上口。姓名：`{name}`，职位：`{job}`"
2. 调用模型生成 slogan
3. 打印结果

### 第 5 步：生成结构化名片数据（使用 JsonOutputParser）

使用 `JsonOutputParser` + Pydantic 完成：

1. 定义一个 Pydantic 类 `Card`，包含以下字段：
   * `name`：姓名（字符串）
   * `job`：职位（字符串）
   * `intro`：自我介绍（字符串）
   * `slogan`：个人 slogan（字符串）
   * `skills`：技能列表（字符串数组）
2. 创建 `JsonOutputParser(pydantic_object=Card)`
3. 使用 `parser.get_format_instructions()` 作为 system 提示词
4. 调用模型生成结构化名片数据
5. 打印解析后的字典结果

### 第 6 步：完整运行

在 `if __name__ == "__main__":` 中：

* 测试数据：`name="张三"`，`job="Python 开发工程师"`，`skills="Python, LangChain, FastAPI"`

* 按顺序执行第 3、4、5 步

* 最终打印一张完整的"名片"，格式如下：
  
      ============================
            AI 智能名片
      ============================
      姓名：张三
      职位：Python 开发工程师
      自我介绍：xxxxxx
      个人 slogan：xxxxxx
      技能：Python, LangChain, FastAPI
      ============================
