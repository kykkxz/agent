## 1. 产品概述与背景说明

### 1.1 项目背景

蜀道集团作为大型交通建设企业，业务涵盖高速公路、铁路、港口等交通基础设施建设与运营，安全生产管理是其核心业务之一。当前安全生产管理面临以下挑战：

- **隐患管理效率低**：隐患上报依赖纸质表单或微信群通知，信息流转慢、易遗漏，难以追踪闭环状态。
- **安全知识获取难**：一线员工遇到安全问题时缺乏即时、权威的解答渠道，依赖经验判断，风险高。
- **安全培训考核成本高**：传统线下培训考试组织周期长、覆盖面有限，难以满足全员安全教育的常态化需求。
- **数据沉淀不足**：安全隐患数据分散，缺乏系统化统计分析手段，无法支撑管理层的科学决策。

基于上述痛点，蜀道集团决定通过 AI 技术赋能传统安全管理流程，打造集**隐患排查、智能问答、在线考试**于一体的智能化安全管理平台——「蜀道安全助手」。

### 1.2 产品定位

「蜀道安全助手」是一款面向蜀道集团全体员工的 AI 驱动安全生产管理平台，通过三大核心模块构建安全生产管理的数字化闭环：

| 模块      | 核心能力                      | 价值主张            |
| ------- | ------------------------- | --------------- |
| 隐患安全管理  | 隐患全生命周期管理（上报→派单→整改→验收→闭环） | 隐患闭环率提升，响应时效缩短  |
| AI 智能助手 | 基于企业安全知识库的多轮智能问答          | 安全知识即时可达，降低咨询成本 |
| 考试工坊    | AI 出题、智能组卷、在线考试、自动阅卷      | 培训考核自动化，覆盖面扩大   |

### 1.3 核心目标

1. **隐患闭环率 ≥ 95%**：通过系统化流转与消息通知机制，确保隐患从上报到闭环全程可追踪。
2. **安全知识即时响应**：AI 问答首字响应 ≤ 3 秒，基于企业安全知识库精准回答，消除幻觉。
3. **培训考核全覆盖**：支持全员在线考试，AI 出题降低命题成本 80% 以上。
4. **高并发支撑**：系统支持 ≥ 200 并发用户，AI 问答支持 ≥ 50 QPS。

## 2. 用户角色定义

### 2.1 角色概述

本系统定义三类用户角色，覆盖安全生产管理的各层级参与者：

#### 2.1.1 管理员（Admin）

- **定位**：系统管理者与决策者，通常为安全管理部门负责人或信息中心管理员。
- **职责**：系统配置、用户管理、知识库维护、全局数据统计分析、权限分配。
- **特征**：拥有系统最高权限，可查看和操作所有模块的所有数据。

#### 2.1.2 安全员（Safety Officer）

- **定位**：安全生产管理执行者，通常为各项目/部门专职安全员。
- **职责**：隐患派单与验收、考试组织与阅卷审核、AI 知识库内容审核。
- **特征**：可管理其管辖范围内的隐患和考试，不具备系统级配置权限。

#### 2.1.3 普通员工（Employee）

- **定位**：一线操作人员，涵盖施工人员、技术人员等全体员工。
- **职责**：隐患上报、AI 安全问答咨询、参加在线考试。
- **特征**：仅可操作自己提交的隐患和自己参加的考试，权限范围最小。

## 3. 功能需求描述

### 3.1 隐患安全管理模块

#### H01 — 隐患上报

**用户故事：**

> 作为一名普通员工，我希望能够通过手机快速上报发现的安全隐患，包括拍照、描述隐患信息并选择隐患等级，以便安全管理人员及时获知并处理。

**功能描述：**

- 支持填写隐患标题、详细描述、发生位置（支持地图选点）、发生时间。
- 支持现场拍照上传（最多 9 张），支持多段视频上传（最多 3 段，单段 ≤ 50MB）。
- 需选择隐患等级：重大隐患、较大隐患、一般隐患、轻微隐患。
- 需选择隐患类别：如高处作业、临边防护、机械伤害、消防安全、临时用电等。
- 可选择隐患所属项目/标段。
- 上报后自动生成隐患编号，状态为「待处理」。
- 支持离线缓存，网络恢复后自动上报。

**验收标准：**

1. 上报页面首屏加载时间 ≤ 2 秒。
2. 图片上传支持压缩，单张压缩后 ≤ 2MB，上传成功率 ≥ 99%。
3. 必填字段未填写时，提交按钮置灰并给出提示。
4. 上报成功后，生成唯一隐患编号（格式：HD-YYYYMMDD-XXXX），并跳转至隐患详情页。
5. 离线模式下提交的隐患标记为「待同步」，联网后 10 秒内自动同步。
6. 上报成功后，系统自动向辖区安全员推送消息通知（见 H08）。

---

#### H02 — 隐患列表

**用户故事：**

> 作为一名安全员，我希望能够查看管辖范围内的所有隐患列表，并按状态、等级、时间进行筛选和排序，以便快速掌握隐患整体情况。

**功能描述：**

- 列表展示字段：隐患编号、标题、等级（带颜色标签）、状态、上报人、上报时间、所属项目。
- 支持多维度筛选：隐患等级、状态流转、隐患类别、时间范围、所属项目。
- 支持关键字搜索（标题、编号、描述）。
- 支持按上报时间、紧急程度排序。
- 分页展示，每页默认 20 条，支持切换 10/20/50 条。
- 列表项点击跳转至隐患详情（H03）。
- 普通员工仅可见本人上报的隐患。

**验收标准：**

1. 列表数据加载时间 ≤ 500ms（接口响应）。
2. 筛选条件切换后，列表 1 秒内刷新。
3. 不同角色看到的数据范围符合权限矩阵定义。
4. 隐患等级以颜色标签区分：重大（红色）、较大（橙色）、一般（黄色）、轻微（蓝色）。
5. 空数据时展示友好空状态提示。

#### H03 — 隐患详情

**用户故事：**

> 作为一名安全员，我希望能够查看某条隐患的完整信息，包括上报内容、图片、处理过程记录和当前状态，以便全面了解隐患情况并做出处理决策。

**功能描述：**

- 展示隐患基本信息：编号、标题、描述、等级、类别、位置、上报时间、上报人。
- 展示现场图片/视频，支持点击放大查看（图片支持手势缩放）。
- 展示隐患状态流转时间线：每个状态节点的操作人、操作时间、备注。
- 展示处理记录：派单信息、整改反馈、验收结果。
- 根据当前状态和用户角色，动态展示操作按钮：
  - 待处理 + 安全员/管理员 → 显示「派单」按钮。
  - 待验收 + 安全员/管理员 → 显示「验收」按钮。
  - 已驳回 + 被指派人 → 显示「重新整改」按钮。
- 支持导出隐患详情单（PDF 格式）。

**验收标准：**

1. 详情页加载时间 ≤ 1 秒。
2. 图片预览支持左右滑动浏览、双指缩放。
3. 状态流转时间线完整展示所有历史节点，不可篡改。
4. 操作按钮的显示/隐藏严格遵循角色权限与当前状态。
5. PDF 导出内容完整、格式规范，生成时间 ≤ 5 秒。

#### H04 — 隐患派单

**用户故事：**

> 作为一名安全员，我希望能够将待处理的隐患指派给具体的责任人，并设置整改期限和整改要求，以便推动隐患及时整改。

**功能描述：**

- 选择整改责任人（支持按部门/项目筛选人员）。
- 填写整改要求（必填）。
- 设置整改截止日期（必填，不早于当前日期）。
- 可上传附件（整改指导文件等，最多 5 个文件）。
- 可设置优先级：紧急、高、中、低。
- 派单后隐患状态从「待处理」变更为「处理中」。
- 系统自动向被指派人推送消息通知（见 H08）。
- 若整改期限临近未反馈，系统自动发送催办通知。

**验收标准：**

1. 派单操作完成后，状态立即变更为「处理中」，时间线新增派单节点。
2. 被指派人收到消息通知的延迟 ≤ 5 秒。
3. 整改截止日期到达前 24 小时未收到反馈时，自动发送催办通知。
4. 重大隐患派单时，强制要求填写整改要求且整改期限 ≤ 7 天。
5. 派单信息不可重复提交（防抖处理）。

---

#### H05 — 整改反馈

**用户故事：**

> 作为一名被指派整改的员工，我希望能够提交整改完成情况，包括整改措施说明和整改后照片，以便安全员进行验收。

**功能描述：**

- 填写整改措施描述（必填，不少于 20 字）。
- 上传整改后照片（必填，至少 1 张，最多 9 张）。
- 可上传整改相关附件（如维修单据等）。
- 填写整改完成时间（默认当前时间）。
- 提交后隐患状态从「处理中」变更为「待验收」。
- 系统自动向派单安全员推送消息通知。
- 若整改被驳回，状态变为「已驳回」，可重新提交整改反馈。

**验收标准：**

1. 提交整改反馈后，状态立即变更为「待验收」。
2. 整改后照片与上报照片支持对比查看（左右分屏/滑动对比）。
3. 整改措施描述少于 20 字时，提交按钮置灰并提示。
4. 驳回后重新提交时，保留驳回原因展示，并记录新一轮整改信息。
5. 消息通知延迟 ≤ 5 秒。

#### H06 — 隐患验收

**用户故事：**

> 作为一名安全员，我希望能够对整改完成的隐患进行验收，查看整改前后对比并给出验收结论，以便闭环隐患或驳回重新整改。

**功能描述：**

- 展示隐患原始信息和整改反馈信息。
- 支持整改前后照片对比查看。
- 填写验收结论：通过 / 驳回（二选一）。
- 填写验收意见（通过时选填，驳回时必填，不少于 10 字）。
- 可上传验收附件（现场复核照片等）。
- 验收通过：状态变为「已闭环」，隐患流程结束。
- 验收驳回：状态变为「已驳回」，触发整改人重新整改。
- 验收结果记录在状态流转时间线中。

**验收标准：**

1. 验收通过后状态变更为「已闭环」，不可再操作。
2. 验收驳回时必须填写驳回原因，否则无法提交。
3. 驳回后系统自动通知整改责任人，延迟 ≤ 5 秒。
4. 已闭环的隐患在列表中显示绿色闭环标识。
5. 验收操作记录（操作人、时间、结论、意见）完整写入时间线。

#### H07 — 统计分析

**用户故事：**

> 作为一名管理员，我希望能够通过可视化图表查看隐患数据的统计分析，包括趋势、分布、闭环率等，以便为安全管理决策提供数据支撑。

**功能描述：**

- **隐患总览看板**：总隐患数、待处理数、处理中数、已闭环数、闭环率、平均闭环时长。
- **趋势分析**：按日/周/月/季度展示隐患上报量与闭环量折线图。
- **等级分布**：饼图展示各等级隐患占比。
- **类别分布**：柱状图展示各隐患类别的数量。
- **项目分布**：地图/柱状图展示各项目/标段的隐患数量。
- **闭环率统计**：按项目、按安全员统计闭环率排名。
- **时效分析**：平均响应时间、平均整改时间、平均验收时间。
- 支持时间范围筛选和导出 Excel 报表。
- 安全员仅可查看管辖范围内的统计数据。

**验收标准：**

1. 看板数据加载时间 ≤ 2 秒。
2. 图表使用 ECharts 渲染，支持鼠标悬停查看数值。
3. 统计数据与隐患列表数据一致（实时同步）。
4. Excel 报表导出时间 ≤ 10 秒，格式规范。
5. 数据范围严格遵循权限控制。

#### H08 — 消息通知

**用户故事：**

> 作为一名普通员工，我希望能够及时收到隐患相关的消息通知（如被派单、整改被驳回、验收结果等），以便第一时间响应处理。

**功能描述：**

- **通知类型**：
  - 隐患被派单（通知整改责任人）。
  - 整改反馈已提交（通知派单安全员）。
  - 验收通过/驳回（通知整改责任人）。
  - 整改催办（临近截止日期提醒）。
  - 考试通知（考试开始提醒、成绩发布）。
- **通知渠道**：站内消息（铃铛图标红点提示）。
- **消息列表**：按时间倒序排列，未读消息高亮，支持全部标记已读。
- **消息详情**：点击消息跳转至对应业务详情页。

#### A05 — 知识检索

**用户故事：**

**功能描述：**

- 知识库来源：安全生产法律法规、企业安全操作规程、事故案例库、应急预案等。

- 知识库分片管理：文档按语义段落自动分片，支持调整分片参数。
- 检索结果展示：回答中标注引用的知识来源（见 A06）。
- 支持知识库分类管理：按法规类、规程类、案例类等分类。
- 知识库更新后，增量向量化，不影响在线检索。
- 安全员可对知识库内容进行审核（准确性、时效性）。

**验收标准：**

1. 知识检索耗时 ≤ 1 秒（不影响首字响应 ≤ 3 秒的总目标）。
2. 检索 Top-K（K=5）相关文档片段参与回答生成。
3. 文档上传后 5 分钟内完成解析和向量化入库。
4. 知识库支持 ≥ 10000 篇文档，检索准确率 ≥ 85%。
5. 知识库内容更新后，新回答能引用到最新内容。

5. 成绩发布后考生即时收到通知。

#### E06 — 考试记录

**用户故事：**

> 作为一名普通员工，我希望能够查看自己的考试记录和成绩详情，以便了解自己的安全知识掌握情况。

**功能描述：**

- **我的考试列表**：展示已参加的所有考试记录，包含试卷名称、考试时间、成绩、是否通过。
- **成绩详情**：
  - 总分、是否通过（及格/不及格）。
  - 每题作答详情：题目、我的答案、正确答案、得分、解析。
  - 简答题展示 AI 阅卷评分理由。
- **考试报告**：个人能力分析，按知识点分类展示得分率，弱项推荐学习内容。
- **历史趋势**：多次考试成绩趋势图。
- 安全员/管理员可查看所有人的考试记录（权限范围内）。
- 支持导出个人考试成绩单（PDF）。

**验收标准：**

1. 考试记录列表加载时间 ≤ 1 秒。
2. 成绩详情页展示完整答题信息和正确答案。
3. 简答题展示 AI 评分理由和人工调整记录（若有）。
4. 个人能力分析图表清晰，弱项推荐合理。
5. PDF 成绩单导出时间 ≤ 5 秒。

#### E07 — 统计分析

**用户故事：**

> 作为一名管理员，我希望能够查看考试数据的统计分析，包括参考率、通过率、成绩分布等，以便评估安全培训效果。

**功能描述：**

- **考试总览看板**：考试场次总数、参考人数、平均参考率、平均通过率、平均分。
- **单场考试分析**：
  - 参考率 / 缺考率。
  - 成绩分布（直方图）：90+、80-89、70-79、60-69、<60。
  - 平均分、最高分、最低分、中位数。
  - 每题得分率/错误率（错题分析）。
  - 知识点掌握度热力图。
- **多场考试对比**：选择多场考试对比通过率、平均分趋势。
- **人员分析**：按部门/项目统计参考率和通过率排名。
- **错题 TOP 榜**：错误率最高的题目排名，辅助知识薄弱点识别。
- 支持时间范围筛选和数据导出（Excel）。
- 安全员仅可查看管辖范围内的统计数据。

**验收标准：**

1. 统计看板加载时间 ≤ 2 秒。
2. 图表数据与考试记录数据一致。
3. 错题分析按错误率降序排列，展示题干摘要。
4. Excel 导出包含明细数据和汇总数据，时间 ≤ 10 秒。
5. 数据范围严格遵循权限控制。

#### E08 — 题目审核

**用户故事：**

> 作为一名安全员，我希望能够审核 AI 生成的题目，检查题目准确性、答案正确性和表述规范性，以便确保入库题目的质量。

**功能描述：**

- **待审核列表**：展示所有 AI 生成且待审核的题目，按生成时间排序。
- **审核操作**：
  - 通过：题目正式入库，状态变为「已发布」。
  - 驳回：题目退回，需填写驳回原因（答案错误/题干不规范/知识点不符/其他）。
  - 编辑后通过：直接在审核界面编辑修改题目后通过。
- **批量审核**：支持选中多题批量通过/驳回。
- **审核详情**：展示题目完整信息、AI 生成参数、引用知识来源。
- **审核记录**：记录审核人、审核时间、审核结论、修改内容。
- **审核统计**：展示待审核数量、本月审核量、驳回率等。
- 驳回的题目可由出题人修改后重新提交审核。

**验收标准：**

1. 待审核列表加载时间 ≤ 1 秒。
2. 审核操作即时生效，状态立即更新。
3. 编辑后通过的题目保留修改记录（修改前/后对比）。
4. 批量审核支持 ≥ 50 题，操作时间 ≤ 5 秒。
5. 审核记录完整可追溯，不可篡改。

### 3.4 安全讲座 PPT 智能制作（方向 A — 简要说明）

> **说明**：本节为模块三方向 A 的简要描述，不在本期实施范围内，作为后续迭代备选方案。

**功能概述：**

安全讲座 PPT 智能制作模块旨在通过 AI 技术帮助安全管理人员快速生成安全培训 PPT，降低培训材料制作成本。

| 功能点    | 编号  | 简要说明                              |
| ------ | --- | --------------------------------- |
| 主题输入   | P01 | 用户输入安全培训主题（如「高处作业安全培训」），AI 解析主题意图 |
| 大纲编辑   | P02 | AI 自动生成 PPT 大纲，用户可调整章节结构和内容要点     |
| PPT 生成 | P03 | AI 根据大纲一键生成完整 PPT，包含文字、配图、排版      |
| 模板选择   | P04 | 提供多种安全主题 PPT 模板（企业风格/简约风格/图文风格）   |
| 内容填充   | P05 | AI 基于知识库自动填充每页详细内容，包括案例、法规引用      |
| 在线预览   | P06 | 支持在线翻页预览 PPT 效果，支持全屏演示            |
| 导出下载   | P07 | 支持导出为 .pptx / .pdf 格式，可离线使用       |
| 手动编辑   | P08 | 支持在线编辑 PPT 内容（文字修改、图片替换、页面增删）     |

**与方向 B 的关系：** 方向 A 和方向 B 互为备选方案，本期选择方向 B（考试工坊）实施。方向 A 可在后续版本中作为扩展模块接入，与考试工坊形成「培训→考核」的完整闭环。

| 知识检索耗时     | ≤ 1 秒        | AI 知识检索（RAG）    | 向量检索耗时监控                     |
| 批量导入处理     | 200 条 ≤ 30 秒 | 题库/隐患批量导入       | 接口响应计时                       |
| 图表渲染时间     | ≤ 2 秒        | 统计分析看板          | 前端性能监控                       |
| 消息推送延迟     | ≤ 5 秒        | 站内消息通知          | 事件触发到消息到达计时                  |

**性能保障措施：**

- **前端**：路由懒加载、组件按需加载、图片懒加载与压缩、CDN 静态资源加速、Redis 缓存热点数据。
- **后端**：接口分层缓存、数据库索引优化、SQL 慢查询监控（阈值 1 秒）、连接池配置（SQLAlchemy async engine）。
- **AI**：流式输出减少用户等待感、向量检索异步预处理、大模型 API 请求队列与限流。
- **数据库**：SQLite WAL 模式提升并发读、Chroma 向量索引优化、定期备份 SQLite 数据文件。

### 5.2 安全需求

#### 5.2.1 身份认证与授权

| 安全项  | 要求                                           |
| ---- | -------------------------------------------- |
| 身份认证 | 基于 JWT Token 认证，Token 有效期 2 小时，支持刷新机制        |
| 密码安全 | 密码 BCrypt 加盐存储，强制密码复杂度（≥ 8 位，含大小写字母+数字+特殊字符） |
| 会话管理 | 单设备登录限制（可选），超时自动登出（30 分钟无操作）                 |
| 权限控制 | 基于 RBAC 模型，接口级 + 数据级双重权限校验                   |
| 越权防护 | 所有接口后端校验当前用户是否有权操作目标数据                       |

#### 5.2.2 数据安全

| 安全项      | 要求                                 |
| -------- | ---------------------------------- |
| 传输加密     | 全站 HTTPS，TLS 1.2+                  |
| 敏感数据脱敏   | 日志中手机号、身份证号等敏感字段脱敏处理               |
| SQL 注入防护 | SQLAlchemy ORM 参数化查询，禁止 SQL 拼接       |
| XSS 防护   | 前端输入输出 HTML 转义，CSP 内容安全策略          |
| CSRF 防护  | Token 校验 + SameSite Cookie         |
| 文件上传安全   | 文件类型白名单校验、文件大小限制、文件重命名、存储路径不可执行    |
| 数据备份     | SQLite 数据文件每日全量备份，Chroma 向量库定期快照，保留 30 天 |

#### 5.2.3 AI 安全

| 安全项         | 要求                            |
| ----------- | ----------------------------- |
| 敏感词过滤       | 用户输入和 AI 输出双向敏感词检测，敏感词库定期更新   |
| Prompt 注入防护 | 对用户输入进行 Prompt 注入检测，过滤恶意指令    |
| 回答安全审核      | AI 回答内容安全审核，不输出违规、违法内容        |
| 知识库隔离       | AI 仅基于企业知识库回答，不泄露系统提示词和内部架构信息 |
| 速率限制        | 单用户 AI 问答频率限制（≤ 10 次/分钟），防止滥用 |
