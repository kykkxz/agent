### 1.1神经网络基础

```
输入层--隐藏层--输出层
```

- 前向传播：数据从输入层到输出层，逐层传递

- 损失函数：衡量预测值与真实值的差距

- 反向传播：通过链式法则来计算梯度

- 梯度下降：沿梯度的反方向更新参数

数学表达：

```
z = W·x + b
a = activation(z)
Loss = L(y_pred, y_true)
∂Loss/∂W = ∂Loss/∂a · ∂a/∂z · ∂z/∂W
```

### 1.2 常见激活函数

1.激活函数起什么作用？

神经网络的核心组件：为网络加入非线性能力，提升网络的复杂性

| 激活函数          | 公式                      | 特点                  | 适用场景       |
| ------------- | ----------------------- | ------------------- | ---------- |
| Sigmoid（记住图像） | σ(x) = 1/(1+e⁻ˣ) （记住公式） | 输出[0,1]，易梯度消失       | 二分类输出层     |
| Softmax       | σ(xᵢ) = eˣⁱ/Σeˣʲ（记住公式）  | 多分类概率归一化            | 多分类/RNN/内部 |
| Tanh（记住图像）    |                         |                     |            |
| Relu（记住图像）    | f(x) = max(0,x)         | 计算快，缓解梯度消失          | 隐藏层默认选择    |
| Leaky ReLU    | f(x) = max(αx, x)       | 解决Dead ReLU问题       | ReLU效果不佳时  |
| GELU          | f(x) = x·Φ(x)           | 平滑非线性，Transformer常用 | BERT/GPT等  |

**为什么BERT/GPT从Relu改用Gelu？**

* **平滑性**: GELU 是平滑函数，ReLU 在 x=0 处不可导
* **随机正则化效果**: GELU(x) = x·Φ(x)，Φ 是标准正态 CDF，相当于输入依赖的 dropout
* **大模型表现更好**: Google 实验验证，GELU 比 ReLU 在大规模预训练上效果更优

**为什么大模型又偏爱 SiLU (Swish)？**

```
# SiLU (Sigmoid Linear Unit)
def silu(x):
    return x * torch.sigmoid(x)

# 特点:
# 1. 非单调: 比ReLU更灵活
# 2. 平滑: 比GELU计算简单
# 3. 梯度: 在所有点可导，训练更稳定
# 4. 性能: 在大模型上验证效果更好
```

#### 2.1 RNN：

循环神经网络（Recurrent Neural Networks, RNN）是一类神经网络架构，专门用于处理序列数据，能够捕捉时间序列或有序数据的动态信息，能够处理序列数据，如文本、时间序列或音频。

![1_dznTsiaHCvRc70fxWWEcgw](https://www.runoob.com/wp-content/uploads/2024/12/1_dznTsiaHCvRc70fxWWEcgw.png)

非首个时间的输出都依赖于当前时间点的输入以及前面时间点的一些状态输出

弊端：

- 梯度消失：长序列中早期的信息会的丢失

- 梯度爆炸：梯度累计导致数值不稳定

- 短期记忆：只能记住较近的信息

#### self-attention计算过程：

```
step1：为每个词创建Q,K,V三个向量（权重加成）
step2：计算出注意力分数
  score(Q_i, K_j) = Q_i · K_j / sqrt(d_k)
step3：sofxmax归一化
  attention_weights = softmax(scores)
step4：加权求和
  output = Σ attention_weights_i * V_i
```

```
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V
```

- Q,K,V分别是query，key和value矩阵

- dₖ 是 Key 的维度

- √dₖ 是缩放因子，防止点积过大导致 softmax 饱和

![v2-4f4958704952dcf2c4b652a1cd38f32e_1440w](https://pic1.zhimg.com/v2-4f4958704952dcf2c4b652a1cd38f32e_1440w.jpg)

本身512维，设置8个头 cat拼接起来，qkv的尺寸必须是d_k=d_model/h = 512/8=64

- 1.输入特征[batch, seq_len, d_model]

- 2.线性投影，拆分成h个头-->得到h组Q,K,V:[batch, seq_len, d_k] (d_k=d_model/h)

- 3.每个头单独计算缩放点积注意力

- 4.把h个头的输出在特征维度进行拼接

- 最终拼接完后维度又变回了d_model
  480 维--> 512维（很浪费，这一层线性映射没有必要存在）也不能直接d_k= d_model,计算量太大，需要考虑效果和效率的平衡

```
class PositionwiseFeedForward(nn.Module):
    """
    逐位置前馈网络：Linear -> ReLU -> Linear -> Dropout
    相当于在每个位置上独立应用同一个 MLP。
    """

    def __init__(self, d_model, d_ff, dropout=0.1):
        super().__init__()
        self.linear1 = nn.Linear(d_model, d_ff)
        self.linear2 = nn.Linear(d_ff, d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # x: (batch, seq_len, d_model)
        return self.linear2(self.dropout(F.relu(self.linear1(x))))
```

```python
import torch
from datasets import load_dataset
from transformers import AutoTokenizer, AutoModelForTokenClassification, TrainingArguments, Trainer, DataCollatorForTokenClassification
import evaluate
import numpy as np
import json

#1.加载数据集
dataset = load_dataset("json", data_files={"train": "train.json"})

with open("label.json", "r", encoding="utf-8") as f:
    label_dict = json.load(f)
label_list = [""] * len(label_dict)
for k, v in label_dict.items():
    label_list[v] = k
# print(label_list)

small_data = dataset["train"].select(range(int(len(dataset["train"]) * 0.05)))
split_data = small_data.train_test_split(train_size=0.8, seed=42) 
dataset["train"] = split_data["train"]
dataset["validation"] = split_data["test"]

print("训练数据量：", len(dataset["train"]))  
print("验证数据量：", len(dataset["validation"]))  

#2.加载分词器和模型
model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForTokenClassification.from_pretrained(
    model_name, num_labels=len(label_list)
)

# 3. 数据预处理
def tokenize_and_align_labels(examples):
    tokenized_inputs = tokenizer(examples["tokens"], truncation=True, is_split_into_words=True)
    labels = []
    for i, label in enumerate(examples["tags"]):
        word_ids = tokenized_inputs.word_ids(batch_index=i)
        label_ids = []
        for word_idx in word_ids:
            if word_idx is None:
                label_ids.append(-100)
            else:
                label_ids.append(label[word_idx])        
        labels.append(label_ids)
    tokenized_inputs["labels"] = labels
    return tokenized_inputs

tokenized_dataset = dataset.map(tokenize_and_align_labels, batched=True)

# 4.评估函数
metric = evaluate.load("seqeval")
def compute_metrics(p):
    predictions, labels = p
    predictions = np.argmax(predictions, axis=2)
    true_predictions = [[label_list[p] for (p, l) in zip(prediction, label) if l != -100] for prediction, label in zip(predictions, labels)]
    true_labels = [[label_list[l] for (p, l) in zip(prediction, label) if l != -100] for prediction, label in zip(predictions, labels)]
    results = metric.compute(predictions=true_predictions, references=true_labels)
    return {"f1": results["overall_f1"]}

# 5.训练参数
training_args = TrainingArguments(
    output_dir="./bert_ner_demo",
    per_device_train_batch_size=8,
    num_train_epochs=1,
    eval_strategy="epoch",
    learning_rate=2e-5,
    logging_steps=10,
    save_strategy="no"
)

# 6.开始训练
data_collator = DataCollatorForTokenClassification(tokenizer)  #源代码，数据增强？
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    eval_dataset=tokenized_dataset["validation"],
    data_collator=data_collator,
    compute_metrics=compute_metrics,
)
trainer.train()

# 7.保存模型和分词器
save_path = "./bert_ner_saved_model_new"
model.save_pretrained(save_path)
tokenizer.save_pretrained(save_path)
print(f"\n模型已保存到: {save_path}")

#========================三个测试用例====================
print("\n正在从本地加载模型进行测试...")
tokenizer = AutoTokenizer.from_pretrained(save_path)
model = AutoModelForTokenClassification.from_pretrained(save_path)

device = "cuda" if torch.cuda.is_available() else "cpu"
model.eval()
model.to(device)

def ner_infer(sent):
    inputs = tokenizer(sent, return_tensors="pt", truncation=True).to(device)
    with torch.no_grad():
        logits = model(**inputs).logits
    pred_ids = torch.argmax(logits, dim=-1)[0].cpu().tolist()
    tokens = tokenizer.convert_ids_to_tokens(inputs["input_ids"][0])
    res = []
    for tok, tid in zip(tokens, pred_ids):
        tag = label_list[tid]
        if tag != "O" and tok not in ("[CLS]", "[SEP]"):
            res.append(f"{tok}->{tag}")
    return res

# 3条课堂测试句子
test_texts = [

]

print("\n" + "="*50)
print("BERT-NER 模型测试结果")
print("="*50)
for idx, text in enumerate(test_texts,1):
    print(f"测试样例{idx}：{text}")
    print(f"识别实体：{ner_infer(text)}\n")
```
