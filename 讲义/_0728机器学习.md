## 模块二：线性回归与逻辑回归

**线性回归**是机器学习中最基础的算法

房价：面积/地段/房龄/是否学区房/是否挨着地铁？

```
房价 = w1×面积 + w2×地段评分 + w3×房龄 + b
```

w1、w2、w3就是模型要学习的"权重",b是"偏置"。

损失函数，loss

评估指标：MSE

```
MSE = (1/n) × Σ(预测值 - 真实值)²
```

优化算法：梯度下降



**逻辑回归**：线性回归的基础上sigmoid函数（二分类），softmax函数（多分类）

```
P(正类) = 1 / (1 + e^(-z))
```

其中 z = w×x + b  ，x可以是一个向量X

**LightGBM vs XGBoost对比**:

## 模块四：SVM和KNN

支持向量机(SVM)：核心思想很直观:找一条线,把两类数据分开,而且让这条线离两边的数据都尽可能远。

KNN的思想就是"**近朱者赤,近墨者黑**":  K的选择

* 给定一个新样本,找到训练集中离它最近的K个样本
* 这K个样本中哪个类别最多,新样本就属于哪个类别
* 并没有显式的训练过程，只是把数据存储起来，然后在需要预测的适合计算距离，计算量大
  
  

## 模块五：特征工程和评估指标

###### 特征工程 ：

特征工程是机器学习里最重要的一环。

常见的特征工程的方法：

1.特征缩放：

- 标准化：(x - 均值) / 标准差`,让数据服从标准正态分布

- 归一化：(x - 最小值) / (最大值 - 最小值)`,把数据压缩到[0,1]区间

- 适用场景：SVM/KNN/神经网络等对特征尺度敏感的算法

2.特征编码：

- 独热编码one-hot：把类别转换成二进制向量，比如红，蓝，绿转成[1,0,0][0,1,0][0,0,1]

- 标签编码：把类别转成数字，普通，不错，优秀->1，2，3，注意：只适合有序类别

3.特征选择：

- 过滤法：根据特征和目标的相关性选择

- 包装法：用模型性能来评估特征子集

- 嵌入法：模型训练中自动选择，（如L1正则化，树模型的特征重要性）

4.特征构造：

- 多项式构造：比如把x变成x, x², x³, x1×x2等

- 时间特征：从日期里提取年月日星期数，是否周末等

- 文本特征：TF-IDF，词嵌入embedding
  
  

##### 分类任务的评估指标：

混淆矩阵confusion matrix

```
              预测为正    预测为负
真实为正      TP          FN      ← 真实正类 = TP + FN
真实为负      FP          TN      ← 真实负类 = FP + TN
              ↑ 预测正类    ↑ 预测负类
            = TP + FP   = FN + TN
```

* **TP(真正例,True Positive)**: 真实是正,预测也是正。✅ 判对了
* **TN(真负例,True Negative)**: 真实是负,预测也是负。✅ 判对了
* **FP(假正例,False Positive)**: 真实是负,预测成了正。❌ 误报(冤枉好人)
* **FN(假负例,False Negative)**: 真实是正,预测成了负。❌ 漏报(放走坏人)
  
  

准确率accuracy：预测正确的比例，(TP+TN)/(TP+TN+FP+FN)，整体，数据不平衡结果不可靠

精确率precision：预测为正的里面真正正确的比例，TP/(TP+FP) ，控制误报（冤枉好人）

召回率recall：真实为正中，被找出来的比例，TP/(TP+FN)，控制漏报（不能放走坏人）

F1-Score：精确率和召回的调和平均，2·P·R/(P+R)

FPR：FP/(FP+TN) 

TPR：TP/(TP+FN)



- ROC曲线与AUC：

![da325772-292e-4eb7-8f5b-c8d786a7ffb0](file:///C:/Users/qiuxingyu/OneDrive/Pictures/Typedown/da325772-292e-4eb7-8f5b-c8d786a7ffb0.png)

**AUC(Area Under Curve)**: ROC 曲线下面积,取值 [0,1]。0.5 = 随机猜测,1 = 完美分类。**AUC 不受阈值和类别比例影响**,是不平衡数据的好指标。

**PR 曲线**: 横轴 Recall,纵轴 Precision。当正类极度稀少时,PR 曲线比 ROC 更敏感(ROC 会显得过于乐观)。



**！！！！！！！什么时候用哪个指标?！！！！！！！！！**(面试必问，非常重要):

| 业务场景      | 优先指标            | 原因                |
| --------- | --------------- | ----------------- |
| 癌症/疾病筛查   | Recall 召回率      | 宁可误诊也不能漏诊,漏报代价大   |
| 信用卡欺诈检测   | Recall / PR-AUC | 漏掉一笔欺诈损失大,正样本极稀少  |
| 垃圾邮件过滤    | Precision 精确率   | 不能把重要邮件判成垃圾(误报代价) |
| 推荐系统点击预测  | Precision 精确率   | 推错的会打扰用户          |
| 类别平衡的普通分类 | Accuracy 准确率    | 各类样本相当,准确率可信      |
| 综合考虑且不平衡  | F1 / AUC        | 平衡精确与召回,不受阈值影响    |

尤其对于数据不平衡，一定不要只看准确率！！！！



#### 回归任务的评估指标

* **MSE/MAE**: 预测误差。MSE 对大误差敏感(平方放大),MAE 更鲁棒。
* **R²**: 模型解释的方差比例,越接近1越好。R²<0 说明模型还不如直接用均值预测。
  
  
  
  
  
  

## 模块六：数据不平衡的问题与解决方案

什么是数据不平衡？不同类别的样本差距很大?

解决方案：

- 重采样：改变数据分布
  1）过采样：增加少数类的样本，①复制②SMOTE，插值方法构造新样本
  2）欠采样：抽取一部分

- 损失函数的类别权重
  1.sklearn里面的分类器大部分都支持class_weight='balanced'，直接通过参数，自动按照类别反比设置权重
  2.xgboost没有这个参数，但是xgboost有专门的替代方案：
  
  ①scale_pos_weight = 负类数 / 正类数，全局方法正样本的梯度权重
  ②sample_weight:逐样本自定义权重，更灵活

- 阈值调整：输出0-1的概率
  
  阈值调低，大部分例子1，少部分0，可能性0.5阈值，必须0.9才能预测为1

- 选择合适的评估指标：
  
  选择F1或者（ROC）AUC或者PR-AUC作为评估指标
