```python
from matplotlib import lines
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# 配置字体和负号显示（移除 Windows 默认没有的字体，避免警告）
plt.rcParams["font.family"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False

#基础图表
data = {"月份": [1,2,3,4,5,6], "销售额": [50,80,120,90,150,180]}

print("基础图表：")
print(df)

#折线图
plt.figure(figsize=(8, 4))
plt.plot(df["月份"], df["销售额"], marker="o", color="blue", linewidth=2)
plt.title("销售额趋势")
plt.xlabel("月份")
plt.ylabel("销售额")
plt.grid(False)
plt.show()

#柱状图
plt.figure(figsize=(8, 4))
plt.bar(df["月份"], df["销售额"], color="orange", alpha=0.7)
plt.title("销售额分布")
# plt.xlabel("月份")
# plt.ylabel("销售额")
plt.grid(False, linestyle="--")
plt.show()

#散点图
plt.figure(figsize=(8, 4))
plt.scatter(df["月份"], df["销售额"], color="red", s=50)
plt.title("月份与销售额分布")
plt.xlabel("月份")
plt.ylabel("销售额")
plt.grid(False)
plt.show()
```

核心语法

#折线图
plt.figure(figsize=(8, 4))
plt.plot(df["月份"], df["销售额"], marker="o", color="blue", linewidth=2) #设置x轴，y轴，美化性参数设置

plt.title("销售额趋势") #设置图表名字
plt.xlabel("月份",  fontsize=12)#x轴名字
plt.ylabel("销售额", fontsize=12)#y轴名字
plt.grid()

plt.show()

常用参数说明

* `color`：颜色（red/blue/green/black）
* `linewidth`：线条粗细
* `linestyle`：线条样式（- 实线 -- 虚线 : 点线）
* `marker`：点标记（o 圆圈 s 方块 ^ 三角 *星号）
* `alpha`：透明度（0~1）

#### 4. 核心图表与EDA应用

##### 1.看分布：直方图与核密度图

场景：账单金额主要集中在多少钱？

**直方图 (histplot)**：看频数分布。

```
sns.histplot(data=tips, x="total_bill", kde=True) # kde=True 叠加平滑曲线
```

![账单金额分布直方图](sns_output/01_hist.png)

结论：

- 餐厅的主要客户群体消费能力中等，大多集中在十几美元

- 有少数大客户消费高，但占比很少

- 如果餐厅想搞促销，针对10-20区间的消费套餐做推广



**核密度图 (kdeplot)**：看数据密度，适合对比不同组。

```
sns.kdeplot(data=tips, x="total_bill", hue="sex", linewidth=2)
```

![男女消费账单分布对比](sns_output/02_kde.png)

结论：

- 性别对消费金额有营销，但影响有限

- 男性更倾向于点贵的菜，女性消费相对稳定保守

- 餐厅不需针对男女消费者做差异化的定价策略

##### 2.看分类对比：箱线图与小提琴图 (Categorical)

**箱线图 (boxplot)**：看中位数、四分位数和**异常值（离群点）**

```
sns.boxplot(data=tips, x="day", y="total_bill", hue="time")
```

![每周各时段消费账单箱线图](sns_output/03_boxplot.png)

结束：

- 推出工作日的特价午餐

- 周末中午不开门，节约成本，重点推广周末晚餐套餐



**小提琴图 (violinplot)**：箱线图 + 密度图的结合体。

```
sns.violinplot(data=tips, x="sex", y="tip", hue="smoker", split=True)
```

![吸烟/不吸烟男女小费分布小提琴图](sns_output/04_violin.png)

结论：

- 性别影响不大：小费都差不多

- 吸烟习惯也不影响：

- 小费的标准比较统一

- 偶尔有大手笔的人：男性



**柱状图 (barplot)**：看均值。

```
# errwidth=0 去掉误差线，让图更干净
sns.barplot(data=tips, x="day", y="tip", errwidth=0)
```

![每日平均小费金额](sns_output/05_bar.png)

黑色竖线：误差值，表示数据的波动范围

结论：

- 周末小费多，服务员周末上班更划算

- 周五的消费是最少，波动也大

##### 3.看关系：相关性与回归 (Relational)

场景：想知道“账单越高，小费越高”
**热力图 (heatmap)**：看变量间的相关系数。

```
corr_matrix = tips.select_dtypes(include=[np.number]).corr()
sns.heatmap(
    corr_matrix,
    annot=True,        # 显示相关系数数字
    cmap="coolwarm",   # 冷暖配色
    vmin=-1, vmax=1,   # 数值区间
    square=True,       # 正方形格子
    linewidths=0.5
)
```

![特征相关性热力图](sns_output/06_heatmap.png)

横轴和数轴都必须是数值特征，相关系统是-1到1

总账单与小费：0.68 强正相关

总账单与人数：0.6中等正相关

小费与人数：0.49中等相关，更多取决于总账单而非人数

结论：

- 人数多-总消费多-账单多

- 不存在负相关

- 服务员鼓励顾客点更贵的菜，才有可能得到更高的小费

## 模块四：EDA标准流程清单

#### 第 1 步：数据概览

```
df.head()          # 看前 5 行
df.info()          # 看字段类型和缺失值
df.describe()      # 看数值字段统计信息
df.shape           # 看多少行多少列
```

#### 第2步：数据清洗

* 检查缺失值：`df.isnull().sum()`
* 检查重复值：`df.duplicated().sum()`
* 处理异常值：用箱线图找离群点

#### 第 3 步：单变量分析

* 数值变量：直方图、密度图
* 分类变量：计数柱状图

#### 第 4 步：多变量分析

* 数值 vs 数值：散点图、相关系数热力图
* 数值 vs 分类：箱线图、小提琴图
* 分类 vs 分类：堆叠柱状图

#### 第 5 步：特征工程（机器学习的前置工作）探索

* Pairplot 看特征组合
* 决定哪些特征保留、哪些去掉、哪些需要转换

#### 第 6 步：写分析报告

* 总结关键发现
* 给出业务建议
* 指导下一步建模方向
