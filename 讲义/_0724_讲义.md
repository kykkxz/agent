#### 3.2 缺失值的处理方法

缺失值处理的“四步法”

- 1.丢弃法：
  dp.dropna()：只要改行有空值就直接删除
  dp.dropna(thresh=3):只有当一行中有至少3个非空值才进行保留

- 2.固定值填充：
  df.fillna(0), df.fillna("未知“)。适用于明确缺失代表一种状态状态

- 3.统计值来进行填充：
  -均值：数据分布比较均匀，没有极端异常值的数据
  -中位数：**最推荐**。能够代表大部人的水平
  -众数：适合分类的数据

- 4.分组填充（进阶）：不同组别的统计值进行填充。薪资空缺：比如北京和三线城市，薪资差距巨大，需要按城市分组，用该城市的中位数来填补

```

df['education'].fillna(df['salary'].mode()[0]) #众数
df['education'].fillna("未知) #固定值
df['salary'] = df.groupby(['city', 'position'])['salary'].transform(lambda x: x.fillna(x.median())) #按分组的统计值进行填充
```

#### 3.3 异常值的检测与清洗

1.什么是异常值？

不符合常识或者统计规律，例如：年龄999，身高3.5米

2.核心检测方法：IQR（四分位距法）

* **Q1 (下四分位)**: 25% 的数据小于这个值。
* **Q3 (上四分位)**: 75% 的数据小于这个值。
* **IQR = Q3 - Q1**
* **正常范围**：`[Q1 - 1.5 * IQR, Q3 + 1.5 * IQR]`

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["张三", "李四", "王五", "赵六", "王二","钱八"],
    "salary": [4000, 4500, 5000, 5500, 6000, 100000]  # 100000 是明显的高薪异常
})

print("原始数据:")
print(df)

# 1. 计算四分位
Q1 = df["salary"].quantile(0.25)
# print(f"Q1 (下四分位): {Q1}")
Q3 = df["salary"].quantile(0.75)
# print(f"Q3 (上四分位): {Q3}")
IQR = Q3 - Q1
print(f"IQR: {IQR}")

# 2. 确定正常范围边界
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

print(f"\n📊 统计信息:")
print(f"Q1 (下四分位): {Q1}")
print(f"Q3 (上四分位): {Q3}")
print(f"正常范围: {lower_bound} ~ {upper_bound}")

# 3. 找出异常值
outliers = df[(df['salary'] < lower_bound) | (df['salary'] > upper_bound)]
print("\n🔍 发现的异常值:")
print(outliers)

# 4. 处理异常值
print("\n请选择处理方式：")
print("1. 直接删除（数据量充足时）")
print("2. 用中位数替换（数据量珍贵时）")

# 演示方法 B: 用中位数替换（避免数据量骤减）
df.loc[(df['salary'] < lower_bound) | (df['salary'] > upper_bound), 'salary'] = df['salary'].median()
#df.loc[行条件, 列名称] #按标签取行，对应列的值
#(df['salary'] < lower_bound) | (df['salary'] > upper_bound) # &,|
print("✅ 异常值处理完成 (替换为中位数):")
```

## 模块三：电商数据处理

📦 任务一：电商推荐系统用户行为数据清洗

### 📊 数据集描述：`ecommerce_dirty.csv`

这是一份从电商后台导出的用户点击流日志，包含约 50 条记录。字段包括：用户ID、商品ID、类别、行为类型、时间戳、价格、年龄和设备。**数据中存在的“脏”问题：**

1. **重复点击噪声**：部分用户在同一时间对同一商品产生了完全重复的记录（疯狂点击导致）。
2. **行为类型混乱**：`event_type` 字段中英文混杂且大小写不一，例如同时存在 `view`, `VIEW`, `购买`, `cart`。
3. **设备信息不规范**：`device` 字段带有奇怪的空格（如 ` Android `）且大小写混乱。
4. **年龄越界**：`user_age` 存在负数或超过人类极限（如 120 岁）的异常值。
5. **价格缺失**：部分商品的 `price` 字段缺失（NaN）。
6. **时间戳格式错误**：时间格式五花八门，甚至包含非法字符串 `"Invalid Time"`。

### 🎯 任务要求

请编写脚本 `clean_ecommerce.py` 完成以下清洗步骤：

1. **事件标准化**：将 `event_type` 统一转换为小写英文（`view`, `cart`, `purchase`），未知的默认归为 `view`。
2. **异常剔除**：删除 `user_age` 小于 0 或大于 100 的行。
3. **格式与去重**：将时间戳解析为标准 Datetime 格式，过滤掉无效时间；去除完全重复的行。df["timestamp"] = pd.to_datetime(df["timestamp"], errors="coerce")
4. 扩充：对于时间点接近的操作行为，直接保留最新的instance    # 排序后去重：如果是同用户同商品在极短时间内（视为重复），保留一条    df = df.sort_values(["user_id", "item_id", "timestamp"])    # 这里简单去重：完全相同的 user_id + item_id + event_type 记录    # 实际业务可能根据时间差过滤，这里演示 drop_duplicates    df = df.drop_duplicates(subset=["user_id", "item_id", "event_type"], keep="last")
5. **分组填充**：针对缺失的 `price`，请按照 `category`（商品类别）分组，使用**该类别的中位数**进行填充（若该类别全为空，则用全局中位数兜底）。
6. **设备规范化**：去除 `device` 字段的首尾空格，并将所有值统一转换为小写。

```python
    df["timestamp"] = pd.to_datetime(df["timestamp"], errors="coerce")
    print("00000000")

    print("11111111")

    # df = df.drop(columns=["time_diff"])
```

#### 项目 B：智能农业物联网 (IoT) 传感器数据清洗

**背景**：你正在处理智能大棚的温湿度传感器日志，用于环境监控算法。**数据构造**：请先运行 `construct_dataset_iot.py` 生成 `iot_sensor_dirty.csv`。

**任务要求：**

1. **物理边界约束**：温度不可能低于 -10 度或高于 60 度，电量不可能超过 100 或小于 0。将这些异常值标记为缺失（NaN）。
2. **处理离线状态**：当 `status` 为 "offline" 时，温度和湿度通常是无效的，也应标记为缺失。
3. **时间序列插值**：传感器数据是连续的。使用 `interpolate()` 方法对温度、湿度的缺失值进行线性插值填补（比单纯的均值/中位数更科学）。
4. **时间对齐**：解析 `timestamp`，并删除时间解析失败的脏数据行。

```python
# project_iot_solution.py
# 进阶项目实战二：智能农业传感器数据清洗解决方案

import pandas as pd
import numpy as np

def clean_iot_data():
    print("🚀 开始加载物联网传感器脏数据...")
    try:
        df = pd.read_csv("iot_sensor_dirty.csv")
    except FileNotFoundError:
        print("❌ 未找到文件，请先运行 construct_dataset_iot.py 生成数据。")
        return

    print(f"📊 原始数据形状: {df.shape}")

    # --- 1. 处理时间戳并排序 ---
    print("\n🔧 步骤 1：解析时间并排序...")
    df["timestamp"] = pd.to_datetime(df["timestamp"], errors="coerce")
    df = df.dropna(subset=["timestamp"]) # 删除无效时间行
    # df = df.sort_values("timestamp")
    df = df.sort_values("timestamp").reset_index(drop=True)
    print(df)

    # --- 2. 异常值处理：物理边界约束 ---
    print("🔧 步骤 2：过滤物理上不可能的数值...")

    # 温度范围：-10 到 50 度
    temp_mask = (df["temperature"] < -10) | (df["temperature"] > 60)
    print(f"🔥 发现异常温度数据: {temp_mask.sum()} 条")
    # 策略：异常温度标记为 NaN，后续使用插值填充
    df.loc[temp_mask, "temperature"] = np.nan

    # 电量范围：0 到 100
    batt_mask = (df["battery"] < 0) | (df["battery"] > 100)
    print(f"🔋 发现异常电量数据: {batt_mask.sum()} 条")
    df.loc[batt_mask, "battery"] = np.nan # 标记为 NaN 或用截断值

    # --- 3. 状态过滤与噪声平滑 ---
    print("🔧 步骤 3：处理离线状态数据...")
    # 如果状态是 offline，则温度和湿度通常不可信，置为 NaN
    offline_mask = df["status"] == "offline"
    df.loc[offline_mask, ["temperature", "humidity"]] = np.nan
    print(f"📶 标记离线数据: {offline_mask.sum()} 条")

    # --- 4. 缺失值插值 (Interpolation) ---
    print("🔧 步骤 4：基于时间序列的线性插值...")
    # 设置 timestamp 为 index 以支持基于时间的插值（或者简单线性插值）
    # 传感器数据通常随时间变化连续，使用线性插值 interpolate 最合适
    # 按照等差数列补齐中间空缺数值。
    df["temperature"] = df["temperature"].interpolate(method="linear")
    df["humidity"] = df["humidity"].interpolate(method="linear")

    # 检查插值后头部和尾部是否仍有 NaN（因为无法向外观测）
    df = df.ffill().bfill() # 首尾用邻近值填充

    # --- 5. 去除重复记录 ---
    print("🔧 步骤 5：去除重复记录...")
    df = df.drop_duplicates(subset=["sensor_id", "timestamp"], keep="first")

    # --- 6. 最终检查 ---
    print("\n✅ 清洗完成！数据形状:", df.shape)
    print(df[["timestamp", "temperature", "humidity", "battery"]].head(10))

    # 保存结果
    df.to_csv("iot_sensor_clean.csv", index=False, encoding="utf-8-sig")
    print("💾 已保存清洗后数据到: iot_sensor_clean.csv")

if __name__ == "__main__":
    clean_iot_data()
```
