## 模块一：从Bert到GPT--模型架构的演变

## 1.模型介绍

### 1.1 Bert （Encoder-only）的特点

- 擅长：理解/分类/提取/判断关系

- 局限：只能“填空”，不能自由的写出通顺的文章或者对话，不能做生成式任务

GPT系列（Decoder-only）：解决了文本生成的问题

### 1.2 Encoder vs Decoder

| 特性        | Encoder (BERT)  | Decoder (GPT/LLM) |
| --------- | --------------- | ----------------- |
| **核心任务**  | 理解、分类、预测掩码词     | 生成、补全、对话          |
| **注意力机制** | 双向注意力 (可以看到上下文) | 因果注意力 (只能看到之前的内容) |
| **输入/输出** | 输入序列 -> 输出向量/标签 | 输入序列 -> 输出后续序列    |
| **典型应用**  | 情感分析、NER、搜索排序   | 聊天机器人、文章写作、代码生成   |

## 2.生成策略和超参数

调用大模型生成内容时，需要对解码策略进行调整，也就是超参调整

### 2.1 核心参数

| 参数                   | 含义     | 效果                                             |
| -------------------- | ------ | ---------------------------------------------- |
| **Temperature** (温度) | 控制随机性  | **低 (0.1)**: 稳定、确定、保守<br>**高 (0.8)**: 创意、发散、多变 |
| **Top-p** (核采样)      | 累积概率阈值 | 仅从概率最高的前 $p$ 部分词中选择，保证句子通顺同时增加多样性              |
| **Max Length**       | 最大生成长度 | 限制模型输出 Token 的上限，防止无限生成                        |

- 写公文/代码：T=0.1

- 写诗歌/广告创意：T=0.9



## 3. Prompt Engineering

### 3.1 基本结构

- 2.任务描述
