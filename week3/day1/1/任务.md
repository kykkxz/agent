## 📦 任务一：电商推荐系统用户行为数据清洗

### 📊 数据集描述：`ecommerce_dirty.csv`

这是一份从电商后台导出的用户点击流日志，包含约 50 条记录。字段包括：用户ID、商品ID、类别、行为类型、时间戳、价格、年龄和设备。
**数据中存在的“脏”问题：**

1. **重复点击噪声**：部分用户在同一时间对同一商品产生了完全重复的记录（疯狂点击导致）。
2. **行为类型混乱**：`event_type` 字段中英文混杂且大小写不一，例如同时存在 `view`, `VIEW`, `购买`, `cart`。
3. **设备信息不规范**：`device` 字段带有奇怪的空格（如 `  Android  `）且大小写混乱。
4. **年龄越界**：`user_age` 存在负数或超过人类极限（如 120 岁）的异常值。
5. **价格缺失**：部分商品的 `price` 字段缺失（NaN）。
6. **时间戳格式错误**：时间格式五花八门，甚至包含非法字符串 `"Invalid Time"`。

### 🎯 任务要求

请编写脚本 `clean_ecommerce.py` 完成以下清洗步骤：

1. **事件标准化**：将 `event_type` 统一转换为小写英文（`view`, `cart`, `purchase`），未知的默认归为 `view`。
2. **异常剔除**：删除 `user_age` 小于 0 或大于 100 的行。
3. **格式与去重**：将时间戳解析为标准 Datetime 格式，过滤掉无效时间；去除完全重复的行。
   
   df["timestamp"] = pd.to_datetime(df["timestamp"], errors="coerce")
4. 扩充：对于时间点接近的操作行为，直接保留最新的instance
   
       # 排序后去重：如果是同用户同商品在极短时间内（视为重复），保留一条
   
       df = df.sort_values(["user_id", "item_id", "timestamp"])
   
       # 这里简单去重：完全相同的 user_id + item_id + event_type 记录
   
       # 实际业务可能根据时间差过滤，这里演示 drop_duplicates
   
       df = df.drop_duplicates(subset=["user_id", "item_id", "event_type"], keep="last")
5. **分组填充**：针对缺失的 `price`，请按照 `category`（商品类别）分组，使用**该类别的中位数**进行填充（若该类别全为空，则用全局中位数兜底）。
6. **设备规范化**：去除 `device` 字段的首尾空格，并将所有值统一转换为小写。

## 📦 任务二：智能农业物联网 (IoT) 传感器数据清洗

### 📊 数据集描述：`iot_sensor_dirty.csv`

这是一份来自智能大棚的温湿度传感器日志，包含 60 条按时间序列记录的数据。字段包括：传感器ID、时间、温度、湿度、电量、在线状态。
**数据中存在的“脏”问题：**

1. **物理极限越界**：由于传感器噪声，出现了温度 100.5℃、-50℃ 等物理上不可能的数值；电量也出现了 >100 或 <0 的情况。
2. **离线无效数据**：当 `status` 为 `offline` 时，记录的温湿度数据通常是归零或保持不变的无效值。
3. **连续缺失**：传感器短暂故障导致 `humidity` 出现连续缺失。
4. **重复时间戳**：存在完全相同时间戳的重复记录。

### 🎯 任务要求

请编写脚本 `clean_iot.py` 完成以下清洗步骤：

1. **物理边界约束**：将温度不在 `[-10, 50]` 范围内、电量不在 `[0, 100]` 范围内的异常值标记为 `NaN`。
2. **离线过滤**：如果 `status` 为 `offline`，将该行的温度和湿度也标记为 `NaN`。
3. **线性插值**：针对缺失的温度和湿度，**不要使用均值填充**！请使用时间序列的**线性插值法 (`interpolate`)** 进行填补，并处理首尾可能残留的缺失值。
4. **时间解析与去重**：解析时间戳，删除解析失败的行，并按时间先后顺序排序去重。
