# 自动化数据清洗流水线 — 学生任务说明书

## 一、任务背景

在实际开发中，AI Agent、RAG 知识库、机器学习建模、可视化报表等场景都需要**高质量的干净数据**。但现实中的原始数据往往存在：
- 缺失值（空单元格、None、NaN）
- 异常值（不合理极大/极小值、录入错误）
- 格式混乱（邮箱不规范、文本含空白字符）
- 重复记录

你的任务是**从零实现一个自动化数据清洗决策流水线**，让程序根据预设规则自动判断并处理脏数据，最终输出可直接用于下游业务的数据集。

## 三、核心类与函数说明

### `AutoDataCleaner` 类

| 成员 | 类型 | 说明 |
|------|------|------|
| `__init__` | 构造方法 | 接收原始 DataFrame，初始化可配置阈值 |
| `handle_missing_value` | 方法 | 缺失值自动化处理 |
| `handle_outlier` | 方法 | IQR 异常值检测与处理 |
| `run_full_clean` | 方法 | 统一入口，按顺序调用上述方法 |

### 详细函数规格

#### `__init__(self, df)`
- **输入**：`df` (pandas.DataFrame) — 原始脏数据
- **初始化属性**：
  - `self.df` — 原始数据的副本（避免修改原数据）
  - `self.col_missing_drop_threshold` — 列缺失率阈值（默认 0.5，即 50%）
  - `self.iqr_scale` — IQR 异常判定系数（默认 1.5）

#### `handle_missing_value(self)`
- **功能**：遍历每一列，根据缺失率执行不同策略
- **决策逻辑**：
  1. **计算缺失率**：`missing_rate = 列缺失数 / 总行数`
  2. **规则 1 — 删除列**：缺失率 > `col_missing_drop_threshold`，标记该列待删除
  3. **规则 2 — 中位数填充**：数值列（`is_numeric_dtype`），用该列中位数填充
  4. **规则 3 — 占位填充**：文本/分类列，用 `"未知/未填写"` 填充
  5. 批量删除标记的列
- **输出**：打印每列缺失率、处理方式；返回处理后的 DataFrame

#### `handle_outlier(self, mode="clip")`
- **功能**：对数值列进行 IQR 异常检测
- **IQR 计算公式**：
  - `Q1` = 第 25 百分位数
  - `Q3` = 第 75 百分位数
  - `IQR = Q3 - Q1`
  - `下限 = Q1 - iqr_scale * IQR`
  - `上限 = Q3 + iqr_scale * IQR`
- **处理策略（mode 参数）**：
  - `"clip"`（推荐）：截断缩尾，超出上下限的值分别设为上限/下限值，**不丢失样本**
  - `"drop"`：删除包含异常值的整行，**谨慎使用**
- **输出**：打印每列异常上下限、异常数量；返回处理后的 DataFrame

#### `run_full_clean(self, outlier_mode="clip")`
- **功能**：清洗流水线统一入口
- **执行顺序**：先调用 `handle_missing_value`，再调用 `handle_outlier`
- **输出**：返回最终清洗完成的 DataFrame

## 四、你需要完成的任务

### 基础任务（必做）

1. **补全缺失值处理逻辑**
   - 遍历所有列，计算缺失率
   - 实现三档决策：高缺失删列 → 数值列中位数填充 → 文本列占位填充

2. **实现 IQR 异常检测**
   - 对每个数值列计算 Q1、Q3、IQR 和上下限
   - 实现 `clip` 截断和 `drop` 删除两种模式

3. **串联流水线**
   - 在 `run_full_clean` 中按正确顺序调用各方法
   - 确保主程序 `__main__` 块能完整运行并导出 CSV

### 进阶任务（选做）

4. **异常记录导出**
   - 新增方法 `export_outlier_records`，将识别到的异常数据单独导出为 `outlier_record.csv`，供业务人工复核

5. **时间序列插值填充**
   - 新增判断逻辑：如果列名包含 `date`、`time` 等关键字，使用前向填充 `ffill()` + 后向填充 `bfill()` 替代中位数

6. **数据质量报告**
   - 清洗完成后自动生成一份 `clean_report.txt`，包含：
     - 原始行数/列数 vs 清洗后行数/列数
     - 各字段缺失率变化
     - 各字段异常值数量及处理策略
     - 删除的列名列表

## 七、提示与注意事项

1. **pandas 常用 API**：
   - 判断列类型：`pd.api.types.is_numeric_dtype(df[col])`
   - 选中数值列：`df.select_dtypes(include=[np.number]).columns`
   - 中位数：`df[col].median()`
   - 分位数：`df[col].quantile(0.25)`
   - 截断：`df[col].clip(lower=lb, upper=ub)`
   - 条件过滤：`df[(df[col] >= lb) & (df[col] <= ub)]`

2. **编码问题**：读取/写入 CSV 时统一使用 `encoding="utf-8-sig"`，确保 Excel 打开不乱码。

3. **避免修改原数据**：在 `__init__` 中务必使用 `df.copy()`，否则会影响原始传入的 DataFrame。
